# 设计原则（草案）

## 1. 研究流程

```
数据 → 数据质量校验 → 策略假设（预注册）→ 回测（含统一成本）→ 稳健性检验 → paper → 实盘（授权）
```

每个阶段都要留下可复核的产物（数据校验报告、预注册条件、回测配置、paper 日志）。

## 2. 硬性规则

1. **成本口径统一**：手续费、滑点、资金费必须写进成本模型，回测不允许"零成本"；
2. **先预注册再回测**：策略的条件、参数、评估期必须在看到结果前固定；
3. **禁止事后调参**：结果不好就记录失败，不允许改阈值/挑区间重跑；
4. **paper 优先**：任何策略先跑 30 天以上 paper，再谈实盘；
5. **风控前置**：最大回撤、单日亏损、杠杆上限、极端行情停手，必须可执行；
6. **密钥隔离**：只使用交易权限（禁止提现），密钥不入库、不上传。

## 3. 新项目的方向（待定）

- [ ] 资金费/基差类（低风险、容量有限）
- [ ] 跨所价差/做市（需要低延迟与更大资本）
- [ ] 事件驱动 / 数据挖掘（先做样本外验证）
- [ ] 组合配置与风险管理

> 具体方向确定后，在此文档补充研究计划与验收标准。
