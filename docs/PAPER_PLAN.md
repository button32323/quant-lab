# Paper 验证计划（30 天）

> 目的：在不动用真实资金、不需要交易所账户的前提下，用公开数据验证 A0（PURR+HYPE 资金费 carry）的**执行细节**与**门禁条件**。
> 当前环境提示：近 30 天资金费折算年化约 **+9.7%**（略低于 10% 门槛），paper 很可能因环境而不过关——这本身就是有效结论。

## 1. 策略参数（冻结，不可调）

| 项 | 设定 |
|---|---|
| 本金 | 虚拟 $1,000 |
| 资产 | PURR（现货+PURR 永续）、HYPE（现货+HYPE 永续） |
| 仓位 | 每资产 sleeve $500；名义 N = sleeve/(1+1/maxLev)，PURR maxLev=3、HYPE maxLev=10 |
| 方向 | 买现货 + 空永续，1x delta 中性 |
| 成本 | 建仓 0.415% × 名义；资金费按小时结算；调仓成本按真实费率另计 |
| 风控 | 连续 12 次负资金费平仓；回撤 5% 停止；总杠杆 ≤1x |
| 开始/结束 | 启动时确定，固定 30 天 |

## 2. 数据与执行口径

- 数据：Hyperliquid 公开 API（`fundingHistory`、`candleSnapshot`、`metaAndAssetCtxs`），无需密钥；
- 资金费：每 UTC 整点结算，记录逐笔明细（时间、费率、金额）；
- 估值：每小时按 mark price 更新 NAV；每日收盘快照；
- 对账：独立用 API 重算资金费累计，与账面差异必须为 0（容差 $0.01）。

## 2.5 通过概率预期（启动前测算）

按 A0 历史收益 Bootstrap（30 天、block=7、5000 次、**含一次性建仓成本**）：

| 指标 | 近 180 天环境 | 全窗口环境 |
|---|---:|---:|
| 30 天收益中位 | +0.82% | +1.20% |
| 30 天年化中位（含建仓成本） | +5.87% | +10.83% |
| 30 天收益 > 0 概率 | 84.6% | 93.4% |
| 全部门禁通过概率 | **25.0%** | 53.7% |

**结论：当前环境下 30 天 paper 大概率无法通过"年化 >10%"门禁**——一次性的 −0.34% 建仓成本会显著压低 30 天年化读数。因此 paper 的实际意义是：
1. **验证执行/资金费/对账**（必须 100% 正确）；
2. 收益评估应看 **60–90 天** 或同时报告"剔除建仓成本"的年化；
3. 不因 30 天收益低就改参数/改策略。

## 3. 门禁条件（预注册）

| 条件 | 阈值 |
|---|---|
| 运行天数 | ≥ 30 |
| 实现收益 | > 0 |
| 年化收益 | > 10% |
| 最大回撤 | < 5% |
| 资金费正费率占比 | > 60% |
| 资金费独立对账 | PASS |

## 4. 实施步骤

1. 编写 paper 引擎（`src/quantlab/paper.py`）：初始化状态、每小时增量更新、资金费明细、NAV 曲线、报告；
2. 编写运行器（Python 脚本 + Windows 后台进程，每小时执行一次；失败重试、心跳）；
3. 每日任务：对账、备份、体检、日报；
4. 30 天后生成 `PAPER_REPORT.md` 与门禁判定；
5. 通过才讨论实盘；不通过则记录原因（环境 or 执行），不改参数重跑同一段数据。
